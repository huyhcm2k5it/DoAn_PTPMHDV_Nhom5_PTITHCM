# Agent Warning: Do Not Read `.rar` Files

**Stop if you encounter a file with the `.rar` extension.**

- Do not open, extract, analyze, search, or read `.rar` files.
- Do not run commands or tools to access the contents of a `.rar` file.
- Continue working with files that are not in `.rar` format.
- If you need information contained in a `.rar` file, tell the user and ask for guidance; do not access it without permission.
